# Phaser sample

A Phaser 4 game as a developer would ship it: `phaser.min.js` from npm (`phaser@4.2.1`, `dist/phaser.min.js`) beside the game's own script, no bundler. A ship flies over a starfield with the arrow keys or a touch, dodging rocks with arcade physics, and keeps its best time in the game's own browser save.

To update Phaser, copy the new `dist/phaser.min.js` from the npm package over `build/phaser.min.js`.
