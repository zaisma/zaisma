# Zaisma brand

The Z is the brand. Designed by Julius in Affinity Designer 2, based on Futura.

## Which file to use

| Use | File |
|---|---|
| Main logo, on dark backgrounds | `zaisma-wordmark-metal.svg` / `zaisma-mark-metal.svg` |
| One color, on light backgrounds | `zaisma-wordmark-black.svg` / `zaisma-mark-black.svg` |
| One color, on dark backgrounds | `zaisma-wordmark-white.svg` / `zaisma-mark-white.svg` |
| Icons 32 px and smaller | `zaisma-mark-small-black.svg` / `zaisma-mark-small-white.svg` |
| Launches, game jams, merch | `zaisma-mark-tricolor.svg` |
| App icon | `zaisma-app-icon.svg`, `app-icon-*.png`, `apple-touch-icon.png` |
| Browser tab | `favicon.svg`, `favicon.ico`, `favicon-32.png` |

PNG copies of the main files are included at 2048 px (mark) and 2400 px (wordmark).

## Typeface

Headings use **Jost** (`fonts/jost.woff2`, variable weight), a free geometric typeface close to Futura. It's under the SIL Open Font License (`fonts/OFL.txt`). Body text uses the system font.

## Flags

`flags/` holds a 60×45 PNG of each country's flag, shown beside rooms on game pages (where the room runs). They're rendered from [flag-icons](https://github.com/lipis/flag-icons) 7.5.0, under the MIT License (`flags/LICENSE`). They aren't part of the brand; they live here because this folder is what zaisma.com serves as files.

## Rules

- Metal only on dark backgrounds. Its white edges disappear on white.
- Don't rotate, stretch, recolor, outline or add effects to the marks.
- The wordmark is a lowercase z plus custom shard letters "aisma". Don't retype it in a font.
- Bevel edges are 125 units in the Z's 4500-unit drawing (30 px in the Affinity file). The letters use the same thickness.
- Leave clear space around the logo of at least the height of the z's top bar.
- App icon tile color: `#1C1C1C`.
